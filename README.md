## 🚀 VS Code-like File Explorer

A mini file explorer built with inspiration from a machine coding interview round — simulating a simplified version of the VS Code file sidebar.

![Screen Shoot](/public/vsc-explorer.png)

✨ Features

- 📄 Create files (create files inside any folder)
- 📁 Create folders (create folders inside other folders)
- ✏️ Rename files/folders
- ❌ Delete files/folders
- 🔽 Expand and collapse folders
- 💡 Fully interactive and recursive UI

🌳 Example of nesting:

```
📁 Root
├── 📁 backend
│   ├── 📁 routes
│   │   └── 📄 index.js
│   └── 📄 server.js
├── 📁 frontend
│   ├── 📁 components
│   │   └── 📄 PrimaryButton.jsx
│   └── 📄 App.jsx
└── 📄 README.md
```
